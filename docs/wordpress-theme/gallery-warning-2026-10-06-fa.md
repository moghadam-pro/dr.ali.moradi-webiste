# سبک مینیمال هشدار گالری — ۲۰۲۶-۱۰-۰۶

درخواست مالک: بلار کمتر، حذف بلار دوم روی لایهٔ متن، آیکن چشم بستهٔ ارائه‌شده
بالای متن و زیرخط کلمهٔ نمایش.

- بلار thumbnailهای گالری از ۲۲ به ۸ پیکسل کاهش یافت؛ روشنایی از ۰٫۶۵ به
  ۰٫۸۵ و بزرگ‌نمایی از ۱٫۰۸ به ۱٫۰۳ تغییر کرد.
- `gallery-sensitive-warning` دیگر backdrop blur و فرم pill ارث‌رسیده از
  `.gallery-thumb > span` ندارد. پوشش رنگی ۱۲٪، متن ۱۲px با وزن ۵۰۰ و آیکن
  ۲۴px بالای متن استفاده می‌شود.
- نمایش / View / عرض زیرخط دارد. تمام thumbnail همچنان دکمه است و لایهٔ متن
  کلیک را مسدود نمی‌کند.
- محافظت تصویر کامل و جلد دسته‌ها تغییر نکرد؛ بازشدن lightbox با کلیک بررسی
  شد و تصویر کامل همچنان تا اقدام نمایش محافظت‌شده بود.
- اصلاح محدود دو فایل `inc/patients.php` و `assets/css/style.css` از ویرایشگر
  پوسته روی نصب موجود اعمال شد؛ نسخهٔ کامل تازه یا replay GUID نصب/اجرا نشد.
  نسخهٔ قبل از ویرایش بیرون از ریپو ذخیره شد.
- نسخه‌های عمومی EN/FA/AR، SVG، زیرخط و computed backdrop-filter برابر none
  بررسی شدند. syntax PHP، آزمون رفتار بیماران و diff check موفق بودند.
