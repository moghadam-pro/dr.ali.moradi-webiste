# Delivery Roadmap

## Milestone 0 — Discovery foundation

- Consolidate call findings
- Define confirmed scope and exclusions
- Record missing inputs and product risks
- Establish repository and documentation conventions

**Status:** Complete, pending client validation.

## Milestone 1 — Content inventory and references

- Collect all existing content and visual assets
- Review previous design work and legacy websites
- Gather preferred website references
- Validate professional, medical, and company information
- Decide the translation and approval workflow

**Exit criterion:** required assets are inventoried and the visual brief is approved.

## Milestone 2 — Information architecture

- Define audience priorities
- Produce the final sitemap
- Define navigation and multilingual URL strategy
- Map patient, researcher, collaborator, student, and investor journeys
- Define reusable content types for future WordPress conversion

**Exit criterion:** sitemap, page purposes, and content model are approved.

## Milestone 3 — Wireframes

- Create desktop-first page wireframes
- Define responsive behavior for tablet and mobile
- Validate hierarchy, calls to action, and appointment paths

**Exit criterion:** structure and user flows are approved before visual styling.

## Milestone 4 — Visual direction and UI

- Establish typography, color, spacing, and imagery direction
- Design the home page and reusable interface patterns
- Validate Persian, Arabic, and English layouts
- Extend the approved system to all page templates

**Exit criterion:** the complete responsive UI direction is approved.

## Milestone 5 — Interactive implementation

- Build semantic, component-based page templates
- Build maintainable styles and responsive rules
- Implement navigation, page transitions, loading states, motion, and interactions
- Implement forms with validation and accessible feedback
- Integrate multilingual sample or approved content
- Add accessibility and SEO foundations
- Produce a portable static production build

**Exit criterion:** all agreed pages, navigation, forms, states, and interactions work
in the production build across target screen sizes and browsers.

## Milestone 6 — QA and handoff

- Perform content, responsive, accessibility, and browser QA
- Optimize assets and loading behavior
- Document structure and WordPress conversion notes
- Prepare the client-facing handoff package

**Exit criterion:** approved static release and complete handoff documentation.

## Git conventions

- One logical milestone or feature per commit
- Terse, descriptive commit messages
- Documentation updated alongside scope or implementation changes
- No unverified client content presented as final
- Tags may be created for approved milestone handoffs
